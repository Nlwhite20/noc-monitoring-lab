# NOC Monitoring

1. Monitor only localhost and explicitly authorized personal lab systems.
2. Before changes, state the purpose, expected result, rollback, and verification.
3. Bind services to localhost or an isolated lab network by default.
4. Build an alert timeline before proposing a cause.
5. Separate observed evidence from assumptions.
6. State impact, severity, confidence, safe validation, recovery, and prevention.
7. Produce GitHub-safe documentation using placeholders or sanitized evidence.
8. Do not scan, probe, restart, reconfigure, or modify services without explicit approval.
